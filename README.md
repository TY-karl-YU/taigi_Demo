# 🎲 台語大富翁｜TaiGi Monopoly

**臺灣台語教育互動遊戲**  
**版本：台語大富翁 DEMO v1.0（2026）**

以國小學生為主要對象，結合大富翁玩法、台語學習與臺中在地文化，透過互動問答認識台語漢字及生活詞彙。一般民眾亦可免費進行非商業學習與試玩。

## 🎮 線上遊玩

[▶ 開始遊戲（GitHub Pages）](https://ty-karl-yu.github.io/taigi_Demo/)

> 網址須待 GitHub Pages 啟用並完成部署後才可使用。

## 📚 遊戲特色與教學應用

- **台語互動學習**：透過遊戲題目練習台語漢字、詞彙與生活用語。
- **臺中在地文化**：結合地標、歷史建築與文化場景。
- **課堂教學**：教師可投影展示、帶領學生互動或分組活動。
- **課後練習**：學生可透過網址自行學習。
- **公開試玩**：非學生也可免費作個人非商業體驗。

### 使用方式

1. 開啟遊戲網址。
2. 依畫面提示進入台語大富翁。
3. 進行遊戲，透過台語題目與文化內容學習。
4. 教師可依授權條款於非商業課堂展示，並無償提供學生使用。
